# Plan: Fix Textbook JSON Upload Format

## Problem
The admin JSON upload expects a different format than the actual textbook JSON format. The error shows:
- Expected: `{ "chapterName": "...", "subjectName": "...", "class": "...", "content": {...} }`
- Actual: The full textbook JSON directly (with `metadata`, `sections`, etc.)

## Solution
Update the admin JSON upload page to accept the textbook JSON in its native format (same as `electrochemistry_chapter8.json`):

### Changes Needed
1. **Update `requiredFields` for textbooks collection** in `src/app/admin/json-upload/page.tsx`:
   - Change from: `['chapterName', 'subjectName', 'class', 'content']`
   - Change to: `['metadata', 'sections']`

2. **Update `example` format** to show the correct textbook JSON structure

3. **Optional**: Add chapterName extraction logic - when uploading, extract `metadata.chapter_name` to use as the lookup key

## Implementation Notes
- The textbook JSON has `metadata.chapter_name` which should be used for matching (e.g., "তড়িৎ রসায়ন")
- The current chapter page code already queries by `chapterName` field
- No changes needed to the chapter display page since it already handles the data correctly
