# Plan to Fix Student Login Auth Issue and Implement Liquid Glass UI

## Problem Analysis

### Auth Issue
- User reports "auth/unauthorized login" when logging in as student
- Login page uses Google OAuth and sets role to 'student' for new users
- No direct "unauthorized" error found in client code, suggesting Firestore security rules may be blocking student access
- Textbooks page requires login but home page does not
- Need to check Firebase Firestore rules for student role permissions

### UI Request
- Current site has some glassmorphism effects (.glass class in globals.css)
- Home page already uses gradients, blur effects, and glowing elements
- Need to extend liquid glass UI (transparent backgrounds with blur, glowing borders, enhanced gradients) across the entire site
- Apply to all components: cards, buttons, inputs, modals, navigation

## Implementation Steps

### 1. Investigate and Fix Auth Issue
- Examine Firebase Firestore security rules to identify student access restrictions
- Check if rules block student role from accessing certain collections (e.g., textbooks, user data)
- Verify login flow creates proper user document with role: 'student'
- Test login with different user accounts to isolate the issue
- Update rules if needed to allow student access to required resources
- Add proper error handling for auth errors in login component

### 2. Implement Liquid Glass UI Theme
- Update global CSS variables for stronger glass effects (increase backdrop blur, adjust opacity)
- Create new CSS classes for enhanced glassmorphism:
  - Liquid glass with stronger blur and transparency
  - Glowing borders using box-shadow and animation
  - Gradient overlays on glass elements
- Modify component styles across the site:
  - Header/Navigation: Apply glass background with glow
  - Cards: Enhance existing glass class with gradients and glow
  - Buttons: Add glass variants with hover glow effects
  - Inputs/Forms: Glass backgrounds with subtle glow
  - Modals/Dialogs: Full glass overlay with enhanced blur
  - Sidebar/Filter panels: Glass backgrounds
- Update color scheme for better glass effect visibility
- Add CSS animations for liquid-like transitions and glow pulses

### 3. Component Updates
- Update layout.tsx for glass header/navigation
- Modify textbook-card.tsx to use liquid glass
- Update all UI components in components/ui/ directory
- Enhance existing glass elements in home page
- Apply to login/signup pages for consistency

### 4. Testing and Validation
- Test auth fix with student accounts
- Verify glass UI works across different screen sizes
- Check performance impact of blur effects
- Test in both light and dark modes
- Ensure accessibility is maintained with glass effects

## Files to Modify
