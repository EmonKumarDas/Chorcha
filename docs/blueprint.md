# **App Name**: Bangla Education Hub

## Core Features:

- Landing Page: Display a clean, educational landing page with sections for Science, Arts, and Commerce. It includes a navigation bar with 'Home', 'Board Questions', 'MCQ Practice', and 'Explanation' tabs.
- Board Question Filtering: Enable filtering of board questions by year (2018-2025), board (Dhaka, Chittagong, etc.), and question type (CQ/MCQ).
- MCQ Practice: Provide an interface for MCQ practice with immediate feedback (green for correct, red for incorrect) and a step-by-step explanation box.
- Mobile-Responsive Design: Implement a mobile-first design with large buttons, a clean user interface, and a bottom navigation bar for quick access to Home and Profile.

## Style Guidelines:

- Primary color: Deep blue (#1A237E). A classic, intellectual color with an established connection to education and academia. The relatively low saturation prevents this color from appearing garish.
- Background color: Light gray (#F5F5F5). Very light gray creates a neutral backdrop, placing emphasis on the learning materials while complementing the app's sophisticated look.
- Accent color: Indigo (#3F51B5). Using a shade that is slightly different to the primary achieves the right level of differentiation.
- Body and headline font: 'Inter', a sans-serif font, will be used throughout the platform, because it will handle latin script elegantly. 'Hind Siliguri' is another font suggested by the prompt, and may be a suitable alternative; but currently only Google Fonts are supported.
- Employ subject-specific icons (e.g., lab icon for physics, calculator for math) to enhance visual appeal and navigation.
- Utilize a card-based layout for SSC and HSC categories on the landing page.
- Ensure a clean and student-friendly landing page design for easy navigation.
